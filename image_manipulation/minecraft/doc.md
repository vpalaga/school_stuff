generate `.pickle`(saved dict with pos and block data) file with `generator` and use this file in `builder` to 
create `.mcfunction` file inside your minecraft datapack

> `pack.mcmeta` is set for Minecraft version **1.20**
> 
> `Build.generateSingleBlockCommand()` makes a Minecraft function that individualy builds all used blocks in a row,
> so you can check wether an error happends with this block.
